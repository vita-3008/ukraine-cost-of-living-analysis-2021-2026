Звіт дослідження

У цій папці розміщуватиметься підсумковий звіт за результатами дослідження «Аналіз динаміки вартості життя в Україні у 2021–2026 роках».

Звіт міститиме:

актуальність і мету дослідження;

опис джерел даних та методології;

аналіз динаміки споживчих цін;

аналіз інфляції;

порівняння динаміки заробітної плати та цін;

графіки та візуалізації;

рекомендації та висновки.
